# SolarCare — static prototype

Static build of the SolarCare design prototype (multi-org solar panel cleaning console).
Open `index.html`, or start at `Login.dc.html`.

- Each page is a `.dc.html` design component; `support.js` is a small open runtime (built on Preact, MIT) that renders them in any browser.
- All data is sample data; state lives in the tab's sessionStorage.
- Map: Natural Earth geodata (public domain), drawn with Leaflet.
- Inverter / meter / logger product photos © Huawei, from solar.huawei.com.
